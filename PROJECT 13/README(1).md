# Project 13 — Retail Analytics

A Snowflake SQL project implementing and comparing **Star Schema** and **Snowflake Schema** for retail analytics.

### Technology
- Snowflake SQL
- CSV

### Includes
- RAW data ingestion
- Star Schema implementation
- Snowflake Schema implementation
- Revenue analytics
- Regional manager sales report
- Schema comparison and data validation

### Objective
Understand the differences in normalization, redundancy, joins, and query complexity between Star and Snowflake schemas.
