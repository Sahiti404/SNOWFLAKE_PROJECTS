# Project 1: Customer Sales Analytics using Snowflake ❄️

This project analyzes online retail customer sales data using Snowflake Cloud Data Warehouse.

## 📌 Project Overview
- **Database**: `CUSTOMER_SALES_DB`
- **Schema**: `SALES_SCHEMA`
- **Warehouse**: `SALES_WH`
- **Stage**: `SALES_STAGE`

## 📂 Files in this Project
- `customers.csv`: Customer demographic records
- `fooditems.csv`: Menu items and pricing
- `orders.csv`: Transaction records
- `project1.sql`: Complete DDL, staging, COPY INTO commands, analytical queries, and View creation.

## 📊 Key Analytical Queries Covered
1. Total Business Revenue Calculation
2. Top Spending Customer Identification
3. Category-wise & Status-wise Revenue Analysis
4. Customer Purchase Frequency Analysis
5. Reporting View (`CUSTOMER_SALES_REPORT`) Creation
